# Public data package

## Included

### `synthetic/simulated_users_pew_seed42.csv`

The 2,000-row synthetic listener file generated by the submitted notebook's
seed, target values, draw order and column order. It contains no observed people
and no personal identifiers.

It preserves the assessed design, including its limitations: demographic fields
are sampled independently from normalised group listening propensities, and Pew
multi-response topic percentages are normalised into one exclusive preferred
category.

### `aggregates/`

Public-safe aggregate tables describing the Pew inputs and the 500-record
podcast metadata used by the dissertation. No podcast-level rows, titles,
publisher contacts, email addresses, RSS URLs or social-media fields are
included.

## Excluded

The purchased Listen Notes record-level export cannot be redistributed. Listen
Notes permits publication of analysis and aggregate statistics but prohibits
providing its data to third parties. Researchers must obtain equivalent
metadata directly from the provider.

Source and terms: <https://www.listennotes.com/podcast-datasets/>

The source terms also ask researchers to notify Listen Notes when research based
on the data becomes publicly available.

## Rebuild

With a locally licensed metadata export:

```bash
python tools/build_public_data_package.py \
  --metadata /path/to/metadata_with_primary_bucket.csv \
  --output-root data
```
