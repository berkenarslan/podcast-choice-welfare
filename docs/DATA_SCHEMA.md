# Data schema for the assessed pipeline

This document describes the local inputs and BigQuery tables expected by the
assessed dissertation code. It is a contract for reconstruction, not a claim
that the full private pipeline has already been rerun.

## Synthetic listener input

Generated by `notebooks/01_pew_user_simulation.ipynb` with `RNG_SEED = 42` and
`N = 2000`.

| Field | Type | Assessed meaning |
| --- | --- | --- |
| `user_id` | integer | Added before upload to BigQuery; unique listener key |
| `Age Group` | category | `18–29`, `30–49`, `50–64`, or `65+` |
| `Gender` | category | `Male` or `Female` |
| `Education` | category | `High school or less`, `Some college`, or `College+` |
| `Income` | category | `<30K`, `30K–79,999`, or `80K+` |
| `Preferred Category (Pew12)` | category | One simulated preferred topic |
| `Listening Frequency` | category | Five Pew frequency labels |

The notebook draws these fields independently. Demographic inputs are
normalised group-level listening propensities rather than US listener
population margins, and the Pew topic figures are converted from multi-response
percentages to one exclusive category. Those assessed decisions are preserved
only for historical replication.

## Local podcast metadata input

The assessed local export contains 500 podcast records and 38 fields. The
record-level file is not redistributed because it contains provider data and
contact fields. The pipeline uses only the following analytical subset:

| Source field | BigQuery field | Type | Role |
| --- | --- | --- | --- |
| `id_podcast` | `podcast_id` | integer | Alternative key |
| `Primary Bucket (Pew12)` | `primary_bucket` | category | Single supply bucket |
| `has_sponsors` | `sponsor` | boolean/integer | Sponsorship indicator |
| `listen_score` | `listen_score` | numeric | Popularity/quality proxy |
| `listen_score_global_rank` | same | numeric | Fallback popularity proxy |
| `update_frequency_hours` | same | numeric | Source of assessed `timecost_z` |
| `genres` | `genres` | text | Descriptive genre labels |
| `title` | `title` | text | Descriptive title |

The source also contains email and social/contact URL fields. They must never
be committed to this repository.

## Derived BigQuery tables

| Table suffix | Grain | Key checks |
| --- | --- | --- |
| `users_clean` | one row per listener | unique, non-null `user_id` |
| `metadata_features` | one row per podcast | unique `podcast_id`; finite z-scores |
| `bucket_weights` | one row per bucket | finite non-negative `weight_k` |
| `panel_primary_tbl` | listener × podcast | unique (`user_id`, `podcast_id`) |
| `panel_match_only` | listener × in-bucket podcast | at least two alternatives per retained user |
| `panel_match_only_choice` | same | exactly one `chosen = 1` per retained user |
| `panel_match_only_est*` | same | no missing model columns; one choice per user |

## Category coverage in the assessed metadata

The 500-record local metadata contains 11 primary buckets. `Race & Ethnicity`
appears in the 12-topic listener simulation but has no primary-bucket supply.
Users assigned to that category therefore disappear from the match-only
estimation sample, contributing to the reduction from 2,000 simulated users to
1,921 estimated users.
